놀이터 날씨 개인정보 처리방침

시행일: 2026-11-15 · 최종 수정: 2026-11-20

1. 수집하는 정보

놀이터 날씨는 회원가입이 없고 자체 서버가 없습니다. 앱이 다루는 정보는 다음과 같으며 전부 사용자의 기기 안에만 저장됩니다.

  • 위치 정보: 현재 날씨 지역(시군구)을 정하고 주변 놀이터·공원·화장실을 찾기 위해 기기의 위치를 사용합니다. 위치는 기기 밖으로 전송되지 않으며, 마지막 위치만 기기에 저장됩니다. 위치 권한을 거부해도 지역을 직접 선택해 사용할 수 있습니다.
  • 설정 정보: 아이 나이대(최대 4명), 민감군 여부, 우리 동네, 알림 시각(아침·저녁), 즐겨찾기. 기기에만 저장됩니다.
  • 판정 카드 공유: "오늘 판정 공유"를 누르면 기기 안에서 판정 카드 이미지를 만들고, 사용자가 직접 고른 앱(카카오톡 등)으로만 보냅니다. 이미지는 앱 임시 폴더에 잠시 저장되었다가 다음 공유 때 지워지며, 앱이 따로 전송하거나 보관하지 않습니다.

2. 외부에서 받아오는 데이터

앱은 다음 두 곳에서 자료를 내려받습니다. 위치 좌표 자체를 보내지는 않지만, 어느 지역의 자료를 받는지에 따라 대략적인 지역(시군구, 지도에 보이는 범위)이 해당 서버의 접속 기록에 남을 수 있습니다.

  • 공공데이터 정적 파일: 공공데이터로 만든 날씨·미세먼지·장소 목록 파일을 GitHub Pages(github.io)에서 시군구 단위로 내려받습니다.
  • 지도 그림: 지도 화면의 배경 지도는 국토교통부 브이월드(api.vworld.kr)에서 화면에 보이는 범위만큼 받아 옵니다.

이때 일반적인 웹 접속 기록(IP 주소, 요청 시각, 요청한 파일·지도 범위)이 각 서비스에 남을 수 있으나, 앱은 이를 수집하거나 사용자 식별에 쓰지 않습니다.

3. 광고

앱은 Google AdMob 광고를 표시합니다. AdMob(Google)은 광고 제공·측정·부정 사용 방지를 위해 광고 ID 등 기기 식별자, IP 주소로 추정한 대략적인 위치, 광고와의 상호작용, 비정상 종료·진단 정보를 수집할 수 있습니다. 자세한 내용은 Google 광고 정책을 참고하세요. 기기 설정에서 광고 ID 재설정 또는 맞춤 광고 제한이 가능합니다.

4. 알림

아침·저녁 알림은 기기 안에서 예약되는 로컬 알림이며, 알림 서버를 사용하지 않습니다.

5. 아동의 개인정보

이 앱은 보호자(성인)를 대상으로 하며, 아이의 이름·생년월일 등 아동 식별 정보를 입력받지 않습니다. 아이를 여러 명 등록해도 "아이 나이대"(0~2세·3~6세·7세 이상)와 민감군 여부 구분값만 기기에 저장합니다.

6. 정보의 삭제

앱을 삭제하면 기기에 저장된 모든 설정과 즐겨찾기가 함께 삭제됩니다.

7. 데이터 출처

기상청, 한국환경공단(에어코리아), 행정안전부(어린이놀이시설 안전관리시스템, 도시공원·공중화장실 표준데이터, 공중화장실정보), 국립해양조사원(조석예보, 갯벌체험지수), 부산광역시(수유실 정보), 전국농어촌체험휴양마을·도서관·박물관미술관 표준데이터, 행정표준코드관리시스템. 배경 지도는 국토교통부 브이월드를 사용합니다. 공공누리 제1유형(출처표시)에 따라 이용합니다. 판정 결과는 참고용이며 현장 상황과 아이의 상태를 우선해야 합니다.
