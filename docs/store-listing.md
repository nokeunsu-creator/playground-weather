## 자세한 설명 (4,000자)
🛝 오늘 아이랑 나가도 될까?
날씨 앱은 어른 기준입니다. 놀이터 날씨는 0~2세, 3~6세, 7세 이상 아이 기준으로 "나가도 좋아요 / 짧게 다녀와요 / 오늘은 실내 추천"을 한 줄로 알려줍니다.

✅ 아이 기준 외출 판정
- 미세먼지·초미세먼지(환경부 4등급), 체감온도, 비·눈, 바람, 자외선, 꽃가루, 감기가능지수를 한 번에 봅니다.
- 비염·천식 등 민감군이면 더 엄격하게 판정합니다.
- 아이가 여럿이면 최대 4명까지 등록하고, 가장 어린 아이와 민감군 기준으로 판정합니다.
- 기온에 맞는 아이 옷차림과 준비물(선크림, 마스크, 우비, 물…)을 추천합니다.

🕘 언제 나갈까요?
- 오늘·내일 시간대별 판정 띠로 가장 놀기 좋은 시간을 알려줍니다. 이미 지난 시간은 빼고 보여줍니다.

🗺️ 전국 놀이터·공원·화장실 지도
- 행정안전부에 등록된 전국 어린이놀이시설 8만 5천 곳, 도시공원 1만 8천 곳, 공중화장실 3만 3천 곳.
- 그네·미끄럼틀·짚라인 같은 놀이기구와 모래·고무 바닥으로 놀이터를 고를 수 있습니다.
- 공공 놀이터만 보기, 실내 놀이시설, 물놀이형, 기저귀교환대 있는 화장실 필터.
- 카카오맵·네이버지도로 바로 길찾기, 즐겨찾기.

🏛️ 미세먼지 나쁜 날엔 실내에서
- 근처 도서관·박물관과 누구나 이용할 수 있는 실내 놀이터를 추천하고, 지금 운영 중인지 표시합니다.

🦀 갯벌 체험
- 전국 갯벌 체험마을과 체험장을 가까운 순으로 보여줍니다.
- 국립해양조사원 물때(밀물·썰물)와 갯벌체험지수로 체험하기 좋은 시간을 알려줍니다.

📤 판정 카드 공유
- 오늘 판정을 이미지 카드로 만들어 카카오톡 등으로 가족에게 보낼 수 있습니다.

⏰ 아침·저녁 알림
- 등원 전 원하는 시각에 오늘 판정과 옷차림을, 전날 저녁에는 내일 외출 계획을 알려줍니다.

🔒 회원가입 없음, 서버 없음
- 위치와 설정, 아이 나이·민감군은 기기 안에만 저장됩니다. 아이 이름은 받지 않습니다.

📊 데이터 출처
기상청, 한국환경공단 에어코리아, 행정안전부, 국립해양조사원, 공공데이터포털 표준데이터(도서관·박물관·농어촌체험휴양마을), 공공누리 제1유형. 배경 지도는 국토교통부 브이월드. 판정은 참고용이며 아이의 상태와 현장 상황을 우선해 주세요.

## 대상 연령·정책
- 대상: 보호자(성인). 어린이 대상 앱으로 등록하지 않음.
- 개인정보 처리방침 URL: https://nokeunsu-creator.github.io/playground-weather/privacy.html (앱 설정 > 정보에도 링크)
- 데이터 보안 양식(Data safety). 기준: Google 'Google Mobile Ads SDK 의 Play 데이터 공개' 안내(GMA SDK 가 자동 수집·전송하는 항목)
  | 데이터 유형 | 수집 | 공유 | 목적 | 비고 |
  |---|---|---|---|---|
  | 위치 > 대략적 위치 | 예 | 예 | 광고·마케팅, 분석, 사기 방지·보안 | AdMob 이 IP 로 추정. 앱의 정확한 위치 좌표는 기기 안에서만 쓰고 보내지 않음 |
  | 앱 활동 > 앱 상호작용 | 예 | 예 | 광고·마케팅, 분석 | AdMob(광고 노출·클릭) |
  | 앱 정보 및 성능 > 비정상 종료 로그·진단 | 예 | 예 | 분석, 사기 방지 | AdMob SDK |
  | 기기 또는 기타 ID | 예 | 예 | 광고·마케팅, 분석, 사기 방지 | 광고 ID·앱 세트 ID(AdMob) |
  - 전송 중 암호화: 예(HTTPS). 데이터 삭제 요청 수단: 없음(앱이 자체 서버에 저장하지 않음, AdMob 데이터는 Google 정책).
  - 수집이 필수인가: 광고가 들어간 무료 앱이라 필수로 답한다.
  - 앱 자체: 위치 좌표·아이 정보(나이대·민감군)·즐겨찾기·알림 설정은 기기에만 저장, 전송 안 함. 판정 카드 이미지는 사용자가 고른 앱으로만 보냄.
  - 지도 그림(브이월드)·자료 파일(GitHub Pages)을 받을 때 대략적인 지역이 각 서버 접속 기록에 남을 수 있음 → 처리방침 2항.
- 광고 포함 표시: 예.

## 출시 절차 메모
- 개인 개발자 계정: 비공개 테스트 12명 × 14일 후 프로덕션 신청.
- 서명 키는 android/ 밖(예: ~/keys/playweather.jks)에 두고 커밋하지 않기.
- 제출 전 남은 일: AdMob 실제 앱 ID(AndroidManifest)·광고 단위 ID(.env) 넣고 AAB 다시 빌드. (비공개 테스트는 테스트 광고 ID 로 먼저 시작해도 된다)
- 출시 후: 브이월드 '운영키 신청'(개발키 6개월, 최대 3회 연장 / 운영키 2년). 키 값은 그대로라 앱 수정 없음.
